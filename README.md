# 📦 Control de Inventario y Ventas

Proyecto desarrollado por Brayan Camero como parte de mi portafolio de desarrollo de software.

## 📋 Descripción

Sistema desarrollado en Microsoft Excel para facilitar el control de productos, inventario y ventas de pequeños negocios.

El proyecto permite registrar productos, controlar el stock disponible, registrar ventas y obtener un resumen general del negocio mediante fórmulas automáticas.

## 🎯 Objetivo

Crear una herramienta sencilla que permita a pequeños negocios organizar y controlar su inventario y sus ventas de manera práctica.

## ⚙️ Funcionalidades

- Registro de productos.
- Control del stock inicial y stock actual.
- Registro de ventas.
- Cálculo automático del precio de venta.
- Cálculo automático del total de cada venta.
- Actualización automática del inventario.
- Alerta cuando un producto alcanza el stock mínimo.
- Cálculo del valor del inventario.
- Resumen general de las ventas.
- Cálculo del dinero vendido.

## 🛠️ Tecnologías utilizadas

- Microsoft Excel
- Git
- GitHub

## 📊 Estructura del proyecto

### PRODUCTOS

Contiene la información de los productos:

- Código
- Producto
- Categoría
- Stock inicial
- Precio de compra
- Precio de venta
- Stock mínimo
- Valor del inventario
- Estado
- Stock actual

### VENTAS

Permite registrar las ventas realizadas:

- Fecha
- Código del producto
- Producto
- Cantidad
- Precio de venta
- Total

### RESUMEN

Muestra información general del negocio:

- Productos registrados
- Unidades en inventario
- Valor del inventario
- Ventas realizadas
- Dinero vendido
